Tripin

プライバシーポリシー

施行日: 2026年9月12日

Tripinは、旅行中の支出を記録し、地図で確認できるようにするiOSアプリです。 このポリシーでは、アプリで扱う情報と利用者の選択について説明します。

旅行および支出の記録はすべて利用者の端末に保存されます。Tripinは会員登録や 独自サーバーとの同期を提供しません。地図や場所検索を利用する際は、要求した地図の表示範囲や 検索内容が外部サービスに送信されることがあります。

1. 運営者および適用範囲

本ポリシーは、個人開発者が提供するTripiniOSアプリおよびこのプライバシーポリシー ページに適用されます。Tripinはアカウントや独自のバックエンドサーバーを運用して いません。個人情報の取り扱いに関するお問い合わせは、本ポリシー末尾のメールアドレスで受け付けます。

2. 取り扱う情報と利用目的

旅行および支出の記録

旅行名、都市、日程、予算、通貨、支出した場所、カテゴリ、金額、日付、住所、および支出に 保存された場所の位置座標を、旅行の管理、支出の記録、予算や統計の表示に使用します。 これらの記録は利用者の端末に保存され、開発者のサーバーには送信されません。

位置情報

利用者が位置情報の許可を与え、現在地機能または場所検索を使用する際に、現在地を地図の移動と 近くの場所の検索に使用します。アプリはバックグラウンドで位置情報を追跡せず、端末の現在地を 開発者のサーバーに継続的に保存することもありません。

広告および広告に関連する情報

アプリは、広告の表示と関連する同意の管理のために、Google Mobile Ads SDK および Google User Messaging Platform を使用することがあります。Googleは、広告の配信、フリークエンシー 制限、不正利用の防止、効果測定、同意管理の目的で、IPアドレスから推定される大まかな位置、 端末識別子（広告識別子、アプリまたは開発者単位の識別子など）、広告の表示情報、アプリの起動や タップなどの操作、クラッシュ記録、パフォーマンスや診断に関する情報などを処理することがあります。

Google User Messaging Platform は、地域ごとの同意手続きが必要かどうかを確認し、必要な同意画面を 表示するために、ATTの判断前にGoogleと通信することがあります。この段階では広告の要求は行いません。

アプリはこの同意手続きを終えたあと、Google Mobile Ads SDK を開始する前、および広告を要求する前に、 iOS の App Tracking Transparency（ATT）の許可状態を確認します。利用者がATTによる追跡を許可した 場合、端末の広告識別子や他社のアプリ・ウェブサイトでの行動が、パーソナライズ広告や広告効果の測定に 使用されることがあり、その地域で適用される広告同意の選択も併せて反映されます。利用者がATTによる 追跡を許可しない場合、または制限されている場合、アプリは広告のパーソナライズと publisher first-party ID 機能を無効にします。その場合でも、非パーソナライズ広告または制限付き広告の配信、 フリークエンシー制限、集計レポート、不正利用の防止のために、IPアドレス、端末のシグナル、 一部の識別子がGoogleによって処理されることがあります。ATTを許可しない場合でも、旅行の管理、地図、 支出の記録といったアプリの主要な機能は引き続き利用できます。

3. 収集しない情報

アプリは会員登録を提供しておらず、氏名、パスワード、クレジットカード番号、銀行口座情報を求める ことはありません。アプリ内に問い合わせフォームもありません。利用者が下記のメールアドレスに直接 連絡した場合は、メールサービスがメールアドレスと問い合わせ内容を処理することがあります。

4. 外部サービスと情報の送信

アプリの機能提供と広告配信のために、次の外部サービスを使用します。

  • Appleマップ（MapKit）: 地図の表示と場所検索に使用します。 地図を表示・移動する際に、表示中の地図範囲などの一般的なネットワーク情報がAppleによって 処理されることがあります。場所検索を実行すると、検索語と現在地を中心とした検索範囲がAppleに 送信されます。現在地を利用できない場合は、検索精度を高めるために、選択中の旅行に保存された 都市名が検索語に追加されて送信されることがあります。検索結果はアプリのメモリに一時的に 保持されることがあり、旅行の記録として保存していない検索語をアプリの永続的な保存領域に 別途保存することはありません。AppleマップはiOSに組み込まれた機能であり、地図と検索リクエストの 取り扱いはAppleの方針に従います。 Appleプライバシーポリシー
  • Frankfurter 為替レートAPI: 他の通貨で入力した支出を旅行の通貨に換算し、 為替計算機を提供するために使用します。リクエストで送信されるのは 通貨コード2つと基準日のみで、支出金額や旅行・位置の情報は送信しません。 過去の支出にはその日付のレートを、当日以降の支出と計算機には最新のレートを使用します。 取得したレートはアプリのメモリに一時的に保持され、端末の永続的な保存領域には保存しません。 Frankfurter
  • Google Mobile Ads および Google User Messaging Platform: 広告の配信と同意の 管理に使用します。Googleによる情報の取り扱いの詳細は、 Googleプライバシーポリシー および Googleのサービスを使用するアプリにおける情報の取り扱い で確認できます。
  • GitHub Pages: このプライバシーポリシーページの公開ホスティングに使用します。 利用者がこのページを開くと、GitHubがIPアドレス、ブラウザ、リクエスト記録などの一般的な アクセス情報を自社の方針に従って処理することがあります。 GitHubプライバシーステートメント

上記のサービス提供者は、サービスを運営する国を含む海外のサーバーで情報を処理することがあります。 具体的な処理国、保有期間、削除方法、処理方法は、各提供者の方針と利用者の同意の選択に従います。 開発者は、外部サービス提供者が関連する契約、適用される法令、およびAppleの要件に従って適切な水準で 情報を保護するよう、各サービスの規約とプライバシーポリシーを確認したうえで利用します。

5. 保管と削除

旅行および支出の記録は、利用者がアプリ内で削除するまで端末に保管されます。利用者はアプリから 個別の支出、旅行全体、または設定のすべての旅行データを削除で端末に保存された 記録をまとめて削除できます。アプリを削除すると、通常は端末に保存されたアプリの データも削除されます。ただし、iOSのバックアップや端末の設定によるデータの保持については、 Appleの方針と利用者の端末設定によって異なる場合があります。

場所検索サービスおよび広告サービスが処理する情報の保有と削除は、各サービス提供者の方針に従います。 開発者が管理できる情報についての確認または削除のご依頼は、下記のお問い合わせ先で受け付けます。

6. 利用者の選択と権利

  • iPhoneの設定にあるTripinの権限画面から、いつでも位置情報の許可を変更できます。
  • iPhoneの設定の「プライバシーとセキュリティ」>「トラッキング」から、TripinのATTによる追跡の許可を変更できます。
  • アプリ内で旅行と支出の記録を直接編集または削除できます。
  • 設定のデータをエクスポートから、端末に保存された旅行と支出の記録をCSVファイルとして 書き出せます。書き出したファイルは利用者が選んだ保存先やアプリに渡され、開発者には送信されません。
  • 設定のすべての旅行データを削除から、端末に保存された記録を一度に削除できます。
  • その地域で提供されている場合、アプリのプライバシー選択メニューから広告の同意を再確認または変更できます。
  • 開発者が管理する情報の開示、訂正、削除、および個人情報の取り扱いに関するお問い合わせは、下記の連絡先までお送りください。

7. 情報の保護

旅行および支出の記録は、iOSアプリのサンドボックス内に保存されます。外部サービスへのアプリの ネットワークリクエストにはHTTPSを使用します。ただし、いかなる保存方法や送信方法も絶対的な安全性を 保証することはできず、開発者はアプリの機能と取り扱う情報の性質に応じた合理的な保護措置を維持する よう努めます。

8. 子どものプライバシー

Tripinは子どもを対象に設計されたサービスではなく、子どもの個人情報を意図的に収集する ことはありません。子どもの個人情報が処理されたと思われる場合は、下記のお問い合わせ先までご連絡ください。

9. ポリシーの変更

アプリの機能、使用する外部サービス、または関連する法令が変更された場合、このポリシーを改定する ことがあります。重要な変更については、このページまたはアプリを通じてお知らせし、施行日を更新します。
