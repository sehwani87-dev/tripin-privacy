Tripin

隱私權政策

生效日期：2026年9月24日

Tripin 是一款可以幫助你在旅行中記錄行程與支出，並在地圖上查看的 iOS 應用程式。 本政策說明應用程式中處理的資訊以及你可以做出的選擇。

完整的旅行、行程與支出記錄都保存在你的裝置上，Tripin 不提供註冊帳號或自有伺服器 同步功能。你為支出或旅行新增的照片也僅保存在裝置上。使用地圖或地點搜尋時，你請求 的地圖範圍或搜尋內容可能會傳送給外部服務。

1. 營運者與適用範圍

本政策適用於由個人開發者提供的 Tripin iOS 應用程式，以及本隱私權政策頁面。 Tripin 不營運帳號系統或自有後端伺服器。有關個人資料處理的詢問， 可透過本政策末尾的電子郵件地址提出。

2. 處理的資訊與使用目的

旅行、行程及支出記錄

我們會將旅行名稱、城市、期間、預算、貨幣、支出地點、類別、金額、日期、地址， 以及支出所保存地點的位置座標，用於旅行管理、支出記錄、預算與統計顯示功能。 當你新增旅行行程時，我們會將行程名稱、地點名稱、類別、日期與時間、備註以及 地點的位置座標，用於行程管理與地圖顯示功能。這些記錄保存在你的裝置上，不會 傳送到開發者的伺服器。

照片與相機

只有當你要為支出或旅行新增照片時，應用程式才會請求相簿或相機的存取權限。從 相簿選擇的照片以及用相機拍攝的照片，都會保存在你裝置上 Tripin 專用的儲存空間中， 不會傳送到開發者伺服器或其他外部服務。

用相機拍攝的照片，在你確認拍攝後會同時附加到 Tripin 並保存到 iOS 系統相簿中。 如果取消拍攝，則不會保存在任何地方。從相簿中選擇的既有照片，不會重新保存或 複製到系統相簿中。

刪除支出或旅行時，Tripin 專用儲存空間中對應的照片副本也會一併刪除。但是，用 相機拍攝並保存在系統相簿中的原始照片不會被刪除，如需刪除，請直接在 iOS 的 「照片」應用程式中操作。

位置資訊

當你授予位置權限並使用目前位置功能或地點搜尋時，應用程式會將你的目前位置用於 地圖移動以及搜尋附近地點。支出和行程在新增過程中都可以使用相同的地點搜尋功能。 應用程式不會在背景追蹤你的位置，也不會將裝置的目前位置持續保存到開發者的伺服器上。

廣告及廣告相關資訊

應用程式可能會使用 Google Mobile Ads SDK 及 Google User Messaging Platform 來 顯示廣告並管理相關同意設定。基於投放廣告、頻次控制、防止詐騙、成效衡量及同意 管理等目的，Google 可能會處理根據 IP 位址推斷出的大致位置、裝置識別碼（如廣告 識別碼或應用程式／開發者範圍識別碼等）、廣告曝光資訊、應用程式啟動與點擊等產品 互動資料，以及當機記錄和效能、診斷資訊等。

為了判斷特定地區是否需要同意流程並提供相應的同意畫面，Google User Messaging Platform 可能會在 ATT 授權決定之前與 Google 進行通訊。此階段不會請求任何廣告。 應用程式完成該同意流程後，會在啟動 Google Mobile Ads SDK 或請求廣告之前，確認 iOS 的 App 追蹤透明度（ATT）授權狀態。如果你允許 ATT 追蹤，裝置廣告識別碼以及 你在其他公司應用程式／網站上的活動，可能會被用於個人化廣告或廣告成效衡量，並 同時適用你所在地區的廣告同意選擇。如果你不允許或限制 ATT 追蹤，應用程式會關閉 廣告個人化以及 publisher first-party ID 功能。即便如此，為了投放非個人化或受限 廣告、進行頻次控制、彙總報告以及防止詐騙，Google 仍可能處理 IP 位址、裝置訊號 或部分識別碼。無論是否允許 ATT，旅行管理、地圖及支出記錄等應用程式的核心功能 都可以繼續使用。

3. 不蒐集的資訊

應用程式不提供註冊功能，也不會要求提供姓名、密碼、支付卡號或銀行帳戶資訊。 應用程式內也沒有單獨的詢問表單。如果你直接透過下方電子郵件聯絡我們，郵件服務 提供商可能會處理你的電子郵件地址及詢問內容。

4. 外部服務與資訊傳輸

為提供應用程式功能與廣告服務，我們使用以下外部服務。

  • Apple 地圖（MapKit）：用於地圖顯示與地點搜尋。顯示或移動地圖時， Apple 可能會處理正在檢視的地圖範圍等一般網路資訊。執行地點搜尋時，搜尋關鍵字 以及以目前位置為中心的搜尋範圍會傳送給 Apple。若無法取得目前位置，為提高搜尋 準確度，目前所選旅行中保存的城市名稱可能會被附加到搜尋關鍵字中一併傳送。搜尋 結果可能會暫時保存在應用程式記憶體中；未作為旅行記錄保存的搜尋字詞，不會另外 保存在應用程式的永久儲存空間中。Apple 地圖是 iOS 內建功能，地圖與搜尋請求的 處理方式遵循 Apple 的政策。 Apple 隱私權政策
  • Frankfurter 匯率 API：用於將以其他貨幣輸入的支出換算為旅行 貨幣，並提供匯率計算機功能。請求中僅傳送兩個貨幣代碼及基準日期， 不會傳送支出金額或旅行、位置資訊。過去的支出使用該支出發生當日的匯率，今天及 以後的支出與計算機則使用最新匯率。取得的匯率會暫時保存在應用程式記憶體中， 不會另外保存在裝置的永久儲存空間中。 Frankfurter
  • Google Mobile Ads 及 Google User Messaging Platform：用於提供 廣告與管理同意設定。有關 Google 資訊處理方式的詳細內容，可參閱 Google 隱私權政策 以及 使用 Google 服務的應用程式中資訊處理方式說明。
  • GitHub Pages：用於公開託管本隱私權政策頁面。當你開啟本頁面時， GitHub 可能會依照其自身政策處理 IP 位址、瀏覽器及請求記錄等一般存取資訊。 GitHub 隱私權聲明

上述服務提供商可能會在包括其服務營運所在國在內的境外伺服器上處理資訊。具體的 處理國家、保存期限、刪除方式及處理方式，依各提供商的政策及你的同意選擇而定。 開發者會確認各項服務的條款與隱私權政策，以確保外部服務提供商依據相關合約、 適用法律及 Apple 的要求，對資訊提供適當程度的保護。

5. 保存與刪除

旅行、行程及支出記錄會保存在你的裝置上，直到你在應用程式中刪除為止。你可以在 應用程式中刪除單筆支出、單筆行程、整個旅行，或透過設定中的刪除所有 旅行資料一次清除裝置上保存的全部記錄。刪除應用程式通常也會一併刪除 裝置上保存的應用程式資料。不過，是否透過 iOS 備份或裝置設定保留資料，會因 Apple 的政策及你的裝置設定而有所不同。

地點搜尋服務與廣告服務所處理資訊的保存與刪除，依各服務提供商的政策而定。有關 開發者可控資訊的確認或刪除請求，可透過下方聯絡方式提出。

6. 你的選擇與權利

  • 你可以隨時在 iPhone 設定中的 Tripin 權限頁面變更位置權限。
  • 你可以隨時在 iPhone 設定中的 Tripin 權限頁面變更照片及相機權限。
  • 你可以在 iPhone 設定的「隱私權與安全性」>「追蹤」中，變更是否允許 Tripin 進行 ATT 追蹤。
  • 你可以在應用程式中直接修改或刪除旅行、行程與支出記錄。
  • 你可以透過設定中的匯出資料功能，將裝置上保存的旅行與支出記錄匯出為 CSV 檔案。 匯出的檔案會傳送到你選擇的位置或應用程式，不會傳送給開發者。
  • 你可以透過設定中的刪除所有旅行資料一次清除裝置上保存的記錄。
  • 如果所在地區提供相關功能，你可以在應用程式的隱私權選擇選單中重新確認或變更廣告同意設定。
  • 如需查閱、更正或刪除開發者所掌控的資訊，或對個人資料處理有任何疑問，可透過下方聯絡方式提出。

7. 資訊保護

旅行、行程及支出記錄保存在 iOS 應用程式沙盒內部。應用程式與外部服務之間的網路 請求均使用 HTTPS。不過，任何保存或傳輸方式都無法保證絕對安全，開發者會盡力 維持與應用程式功能及所處理資訊性質相符的合理保護措施。

8. 兒童隱私

Tripin 並非專為兒童設計的服務，也不會故意蒐集兒童的個人資料。如果你認為兒童的 個人資料遭到處理，請透過下方聯絡方式告知我們。

9. 政策變更

若應用程式功能、所使用的外部服務或相關法規發生變化，本政策可能會隨之修訂。 重大變更將透過本頁面或應用程式進行說明，並更新生效日期。
