Tripin

隐私政策

生效日期：2026年9月24日

Tripin 是一款可以帮助你在旅行中记录行程与支出，并在地图上查看的 iOS 应用。 本政策说明应用中处理的信息以及你可以做出的选择。

完整的旅行、行程与支出记录都保存在你的设备上，Tripin 不提供注册账号或自有服务器同步功能。 你为支出或旅行添加的照片也仅保存在设备上。使用地图或地点搜索时，你请求的地图范围或 搜索内容可能会发送给外部服务。

1. 运营者与适用范围

本政策适用于由个人开发者提供的 Tripin iOS 应用，以及本隐私政策页面。 Tripin 不运营账号系统或自有后端服务器。有关个人信息处理的咨询， 可通过本政策末尾的邮箱地址提交。

2. 处理的信息与使用目的

旅行、行程及支出记录

我们会将旅行名称、城市、期间、预算、货币、支出地点、类别、金额、日期、地址， 以及支出所保存地点的位置坐标，用于旅行管理、支出记录、预算与统计显示功能。 当你添加旅行行程时，我们会将行程名称、地点名称、类别、日期与时间、备注以及地点的 位置坐标，用于行程管理与地图显示功能。这些记录保存在你的设备上，不会传送到开发者的服务器。

照片与相机

只有当你要为支出或旅行添加照片时，应用才会请求相册或相机的访问权限。从相册选择的 照片以及用相机拍摄的照片，都会保存在你设备上 Tripin 专用的存储空间中，不会传送到 开发者服务器或其他外部服务。

用相机拍摄的照片，在你确认拍摄后会同时附加到 Tripin 并保存到 iOS 系统相册中。 如果取消拍摄，则不会保存在任何地方。从相册中选择的既有照片，不会重新保存或 复制到系统相册中。

删除支出或旅行时，Tripin 专用存储空间中对应的照片副本也会一并删除。但是，用相机 拍摄并保存在系统相册中的原始照片不会被删除，如需删除，请直接在 iOS 的“照片”应用中操作。

位置信息

当你授予位置权限并使用当前位置功能或地点搜索时，应用会将你的当前位置用于地图移动 以及搜索附近地点。支出和行程在添加过程中都可以使用相同的地点搜索功能。应用不会在 后台追踪你的位置，也不会将设备的当前位置持续保存到开发者的服务器上。

广告及广告相关信息

应用可能会使用 Google Mobile Ads SDK 及 Google User Messaging Platform 来展示广告 并管理相关同意设置。出于投放广告、频次控制、防止欺诈、效果测量及同意管理等目的， Google 可能会处理根据 IP 地址推断出的大致位置、设备标识符（如广告标识符或应用／ 开发者范围标识符等）、广告展示信息、应用启动与点击等产品互动数据，以及崩溃记录和 性能、诊断信息等。

为了判断特定地区是否需要同意流程并提供相应的同意界面，Google User Messaging Platform 可能会在 ATT 授权决定之前与 Google 进行通信。此阶段不会请求任何广告。应用完成该 同意流程后，会在启动 Google Mobile Ads SDK 或请求广告之前，确认 iOS 的 App 跟踪透明度（ATT）授权状态。如果你允许 ATT 跟踪，设备广告标识符以及你在其他 公司应用／网站上的活动，可能会被用于个性化广告或广告效果测量，并同时适用你所在 地区的广告同意选择。如果你不允许或限制 ATT 跟踪，应用会关闭广告个性化以及 publisher first-party ID 功能。即便如此，为了投放非个性化或受限广告、进行频次 控制、汇总报告以及防止欺诈，Google 仍可能处理 IP 地址、设备信号或部分标识符。 无论是否允许 ATT，旅行管理、地图及支出记录等应用的核心功能都可以继续使用。

3. 不收集的信息

应用不提供注册功能，也不会要求提供姓名、密码、支付卡号或银行账户信息。应用内也 没有单独的咨询表单。如果你直接通过下方邮箱联系我们，邮件服务提供商可能会处理你的 邮箱地址及咨询内容。

4. 外部服务与信息传输

为提供应用功能与广告服务，我们使用以下外部服务。

  • Apple 地图（MapKit）：用于地图显示与地点搜索。显示或移动地图时， Apple 可能会处理正在查看的地图范围等一般网络信息。执行地点搜索时，搜索关键词 以及以当前位置为中心的搜索范围会传送给 Apple。若无法获取当前位置，为提高搜索 准确度，当前所选旅行中保存的城市名称可能会被附加到搜索关键词中一并发送。搜索 结果可能会暂时保存在应用内存中；未作为旅行记录保存的搜索词，不会另外保存在应用 的永久存储空间中。Apple 地图是 iOS 内置功能，地图与搜索请求的处理方式遵循 Apple 的政策。 Apple 隐私政策
  • Frankfurter 汇率 API：用于将以其他货币输入的支出换算为旅行货币， 并提供汇率计算器功能。请求中仅发送两个货币代码及基准日期，不会 发送支出金额或旅行、位置信息。过去的支出使用该支出发生当日的汇率，今天及以后的 支出与计算器则使用最新汇率。获取到的汇率会暂时保存在应用内存中，不会另外保存在 设备的永久存储空间中。 Frankfurter
  • Google Mobile Ads 及 Google User Messaging Platform：用于提供 广告与管理同意设置。有关 Google 信息处理方式的详细内容，可参阅 Google 隐私政策 以及 使用 Google 服务的应用中信息处理方式说明。
  • GitHub Pages：用于公开托管本隐私政策页面。当你打开本页面时， GitHub 可能会依照其自身政策处理 IP 地址、浏览器及请求记录等一般访问信息。 GitHub 隐私声明

上述服务提供商可能会在包括其服务运营所在国在内的境外服务器上处理信息。具体的 处理国家、保存期限、删除方式及处理方式，依各提供商的政策及你的同意选择而定。 开发者会确认各项服务的条款与隐私政策，以确保外部服务提供商依据相关合约、适用 法律及 Apple 的要求，对信息提供适当程度的保护。

5. 保存与删除

旅行、行程及支出记录会保存在你的设备上，直到你在应用中删除为止。你可以在应用中 删除单条支出、单条行程、整个旅行，或通过设置中的删除所有旅行数据 一次性清除设备上保存的全部记录。删除应用通常也会一并删除设备上保存的应用数据。 不过，是否通过 iOS 备份或设备设置保留数据，会因 Apple 的政策及你的设备设置而 有所不同。

地点搜索服务与广告服务所处理信息的保存与删除，依各服务提供商的政策而定。有关 开发者可控信息的确认或删除请求，可通过下方联系方式提交。

6. 你的选择与权利

  • 你可以随时在 iPhone 设置中的 Tripin 权限页面变更位置权限。
  • 你可以随时在 iPhone 设置中的 Tripin 权限页面变更照片及相机权限。
  • 你可以在 iPhone 设置的“隐私与安全性”>“跟踪”中，变更是否允许 Tripin 进行 ATT 跟踪。
  • 你可以在应用中直接修改或删除旅行、行程与支出记录。
  • 你可以通过设置中的导出数据功能，将设备上保存的旅行与支出记录导出为 CSV 文件。 导出的文件会传送到你选择的位置或应用，不会发送给开发者。
  • 你可以通过设置中的删除所有旅行数据一次性清除设备上保存的记录。
  • 如果所在地区提供相关功能，你可以在应用的隐私选择菜单中重新确认或变更广告同意设置。
  • 如需查阅、更正或删除开发者所掌控的信息，或对个人信息处理有任何疑问，可通过下方联系方式提出。

7. 信息保护

旅行、行程及支出记录保存在 iOS 应用沙盒内部。应用与外部服务之间的网络请求均使用 HTTPS。不过，任何存储或传输方式都无法保证绝对安全，开发者会尽力维持与应用功能 及所处理信息性质相匹配的合理保护措施。

8. 儿童隐私

Tripin 并非专为儿童设计的服务，也不会故意收集儿童的个人信息。如果你认为儿童的 个人信息被处理，请通过下方联系方式告知我们。

9. 政策变更

若应用功能、所使用的外部服务或相关法规发生变化，本政策可能会随之修订。重大变更 将通过本页面或应用进行说明，并更新生效日期。
